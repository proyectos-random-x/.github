# Proyectos Random X

Colección de proyectos web, experimentos frontend y pruebas de interfaz desarrollados con distintas tecnologías y enfoques.

Incluye proyectos realizados con:
- HTML
- CSS
- JavaScript
- React
- Vite
- Tailwind
- Astro
- Supabase

---

## 🚀 Proyectos destacados

Rediseño conceptual moderno del sitio de Ferrovías, enfocado en mejorar presentación y experiencia visual.

🔗 https://github.com/proyectos-random-x/Ferrovias
